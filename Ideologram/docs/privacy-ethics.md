# Privacy & Ethics

- Client-first: run all computation locally unless user opts into cloud services.
- Consent: explicit opt-in for uploads/telemetry; clear data retention policy.
- Transparency: show how each book/item contributed; provide axis definitions.
- Respect: avoid pejorative labels; let users rename/hide axes.
- Control: allow excluding items; easy reset/delete.
- Fairness: avoid overfitting to narrow canons; diversify anchors; routinely audit.
- Documentation: versioned model cards describing data, assumptions, and known limits.
