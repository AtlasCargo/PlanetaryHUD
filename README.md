# PlanetaryHUD

PlanetaryHUD is an interactive 3D planetary interface built with React and Three.js. It visualizes global datasets on a spinning globe to create an engaging and educational experience.

## Features
- Interactive 3D globe rendering with atmospheric effects
- Dynamic opacity control and performance management options
- Ability to load datasets such as population and life expectancy
- Responsive design based on Three.js and TailwindCSS

## Getting Started
1. Clone the repository
   ```bash
   git clone https://github.com/AtlasCargo/PlanetaryHUD.git
   cd PlanetaryHUD
   ```
2. Install dependencies
   ```bash
   yarn install
   ```
3. Start the development server
   ```bash
   yarn start
   ```

## Useful Scripts
- `yarn start` - launches the development server
- `yarn build` - creates an optimized production build

## Project Structure
Source files live in the `src/` directory. Additional notes and the development guide can be found in the `docs/` folder and in `CLAUDE.md`.
